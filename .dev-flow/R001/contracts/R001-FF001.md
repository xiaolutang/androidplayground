## 2. AC（验收标准）

### AC-1：GET /reports（报告列表，分页+过滤）
- 查询参数：`page`（默认 1）、`page_size`（默认 20）、`status`（可选过滤）、`tier`（可选过滤）
- 响应 200：`{items: [ReportSummary], total, page, page_size}`
- ReportSummary：`{id, title, status, tier, created_at, updated_at}`
- 测试：分页 + status 过滤 + tier 过滤 + 空列表

### AC-2：GET /reports/{id}（报告详情）
- 响应 200：`{id, title, status, tier, symptom_type, root_cause, confidence_score, created_at, ...}`
- 响应 404：`{detail: "Report not found"}`
- 测试：正常获取 + 404

### AC-3：GET /reports/{id}/trajectory（假设树可视化数据）
- 响应 200：`{nodes: [HypothesisNode], edges: [{from, to, label}]}`
- 响应 404：报告不存在
- 测试：正常 + 404

### AC-4：GET /reports/{id}/clarify-options（追问候选）
- 响应 200：`{options: [{id, question, context}]}`
- 从 KB 派生候选
- 测试：正常 + 404

### AC-5：POST /reports/{id}/clarify（提交追问答案）
- 请求体：`{answers: [{option_id, value}]}`
- 响应 200：`{accepted: true}`
- 响应 404/409（状态非 assessing）
- 测试：正常提交 + 404 + 409（非 assessing 态）

### AC-6：POST /reports/{id}/regression-feedback（回归反馈）
- **这是最复杂的端点**
- 请求体：`{outcome: "regression" | "safe", evidence: str, bucket_dim?: str, bucket_value?: str}`
- **5 态 allowed**：pr_open/draft_pr/concluded/reflected/reflowed；其他 9 态返回 409
- 处理逻辑：
  1. 写 MetricPoint（metric_type=safety）
  2. outcome=safe → 仅写 MetricPoint，状态不变
  3. outcome=regression + status ∈ {concluded, reflected} → 迁移 → reflowed + 触发回流（路径 B）
  4. outcome=regression + status ∈ {pr_open, draft_pr, reflowed} → 仅写 MetricPoint（不重复触发）
- 响应体：`{metric_point_id, status_before, status_after, reflow_scheduled: bool}`
- 测试矩阵（28 case = 14态×2 outcome）：
  - safe × 5 allowed 态 → 200 + status 不变
  - safe × 9 disallowed 态 → 409
  - regression × {concluded, reflected} → 200 + status_after=reflowed + reflow_scheduled=true
  - regression × {pr_open, draft_pr, reflowed} → 200 + status 不变 + reflow_scheduled=false
  - regression × 9 disallowed 态 → 409

### AC-7：POST /webhook/{platform}（BF001 上报入口）
- 路径参数：platform（crashlytics/sentry/自定义）
- 请求体：平台原始格式（BF001 适配器负责归一化）
- 响应 202：`{bug_report_id, accepted: true}`
- 测试：正常上报 + 未知 platform 400

### AC-8：错误码统一
- 400：参数错（validation error）
- 404：报告不存在
- 409：状态非法（如非 allowed 态调用 regression-feedback）
- 5xx：agent 内部错误
- 测试：覆盖 400/404/409

### AC-9：响应体四字段（regression-feedback）
- `{metric_point_id, status_before, status_after, reflow_scheduled}`
- 四字段必须全部存在
- 测试：断言四字段

### AC-10：测试覆盖
- 全部端点用 TestClient（FastAPI），mock ORB01/BB011/BB015
- ≥ 30 测试覆盖 7 端点 + regression-feedback 28 case 子集
