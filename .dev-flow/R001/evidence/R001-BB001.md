### 实现决策
1. ISMResult 使用 `@dataclass(frozen=True)`，gaps/clarify_questions 用 `field(default_factory=list)` 保证可变默认值安全
2. level 由 `_compute_level(score, threshold_sufficient, threshold_borderline)` 纯函数重算（`>=` 语义），不信任 LLM 返回的 level 字段
3. gaps 过滤通过 `_filter_gaps` 仅保留 A/B/C/D 并去重
4. JSON 解析 `_parse_llm_json` 支持三种格式：```json 围栏 / 裸 JSON / 前缀文字+JSON 提取
5. score 钳制到 [0.0, 1.0]（`_extract_score`），非法/缺失 score 降级 insufficient
6. KB gaps 派生 `_derive_gaps_from_kb` 从 entries 的 content.metadata.gap_hint 或 content.gap_hint 提取候选
7. clarify_questions 仅 borderline 时非空：优先 LLM 生成 -> gaps 模板兜底 -> 通用追问兜底（三级 fallback）
8. LLM 失败（LLMError）/ 非法 JSON / 缺 score 三种场景统一降级 insufficient + degraded=True + reasoning 含 "LLM failure"
9. bug_report duck typing 通过 `_get_field(obj, name, default)` 统一访问（ORM getattr 优先，dict.get 回退）
