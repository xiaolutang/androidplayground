## 关键实现决策

1. **目录命名 agent/signals/（复数）**：对齐 analysis 文档 3.1 项目结构（第 82 行），而非任务描述中的 agent/signal/（单数）。
2. **process_listener 用函数式 API 而非 class**：detect_crash / detect_anr / parse_anr 为纯函数，输入 dict/str 输出 ParsedProcessSignal，无状态更适合信号解析场景。
3. **visual_signal_detector 只检测不决策**：遵循 design D11（锚点库冷启动）+ 3.2 流程图（SIG → BB003/BB004 决策），本模块输出 ParsedVisualSignal 供消费方决策。
4. **logcat stack trace 正则修正**：文件名含点（MainActivity.java），正则用 `[\w.$]+` 匹配文件名部分。
5. **SignalRouter 无消费者返回空列表**：信号被静默丢弃不报错，符合 MVP 降级原则（消费方未注册时不阻断信号采集）。
