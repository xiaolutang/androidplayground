4. staleness 降权：retriever 只读 validity_status，similarity = raw * KB_STALE_DEMOTE 只影响排序与返回值
5. degraded 判定：用 raw_similarity（降权前），避免 stale 条目误导
6. negate_hypotheses：放 retriever.py（同源逻辑），三档用纯函数 _classify_negative
7. StalenessChecker：注入式 commit_distance_fn（无 git subprocess 依赖）；None 返回值保守不标；revalidate_fn 返回 True 即使差异也不标
