1. 7 态迁移矩阵（与 D12 + design 4.1 第 616 行一致）：
   - IDENTIFIED → {WAITING, WONT_FIX}
   - WAITING → {UNBLOCKED, WONT_FIX}
   - UNBLOCKED → {RESOLVED, INVALID_UNBLOCK, WONT_FIX}
   - INVALID_UNBLOCK → {WAITING, WONT_FIX}
   - RESOLVED / WONT_REFLOW / WONT_FIX = 终态（空集）
2. INV-2 守护：delete() 始终抛 GapDeleteError；archive() = transition(WONT_FIX)
3. frequency：count(MetricPoint.ref_gap_type == gap_type) / count(all MetricPoint)

5. UnlockFactors.compute：裁剪到 [0,1] 后相乘
6. 初始状态强制 IDENTIFIED：create() 覆盖传入的 status 字段
